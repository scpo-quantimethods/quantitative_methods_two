1. Turnout and rain

You are interested in knowing whether turnout, the participation in elections, is conditional on weather: that is, do people vote less when it rains? To do so, you are provided with a (fictitious) data set on American elections in 2012, 2016, and 2020.

  1. Using rio and the function import, import the data from https://github.com/scpo-quantimethods/quantitative_methods_two/raw/main/exercices/exercices2/data/rainfall.dta.
  2. Have a look at your data using glimpse(). Drop all variables except voted, voted_prev, rain_mm, age, female, year.
  3. You want to inspect whether the chances of voting change with the rainfall on the day of the election, rain_mm. The variable vote tells if people have voted in the elections. What would be your dependent and independent variables ? Are they categorical or continuous ?
  4. Count the total number of voters and summarize the rain_mm variable. Are there NA’s in the data set ?
  5. Using mutate, case_when, prepare the voted variable for the logistic regression.
  6. Assuming you are estimating a logistic regression, what is the mathematical expression of the probability function as a function of rainfall, denoted \(R_mm\) ? What is the corresponding expression for the logit of that probability? Finally, what is the expression for the odds ratio?
  7. Run a logistic regression with one variable to estimate whether the rain changes anything in the probabilities of voting. For a 1-mm increase in the rainfall, how does the likelihood of voting change ? How significant is that result ?
  8. Does voting in the previous election change the probabilities of voting in the next one ?
  9. Add the variables voted_prev, female, age, rain_mm, as.factor(year) in the predictors, and compare the three models, using the stargazer package;
  10. Use the ggpredict function from package ggeffects to predict the probabilities of voting depending on rain_mm. Have a look at your predictions.
  11. Use ggplot to plot the predicted probabilities with their confidence intervals, with their confidence intervals. Hint : use + geom_ribbon(aes(ymin = conf.low, ymax = conf.high), alpha = 0.2) to display smooth confidence intervals, and geom_line() to add a line connecting the dots.

2. ESS : voting in Italy

You are provided with a simplified dataset containing ESS data for Italy.

  1. Download the dataset and import it into your local environment, using the link https://github.com/scpo-quantimethods/quantitative_methods_two/raw/main/exercices/exercices2/data/ess_it.csv.
  2. Inspect the dataset using glimpse.
  3. Examine the values of the vote variable and modify them using case_when if necessary. Prepare the variable for a logistic regression. Review the other variables as well and modify them as needed. You may draw on the theory section for this session for guidance.
  4. Run a logistic regression to analyze whether the number of years of education influences the probability of voting.
  5. Create a variable age and include the variables polintr, trstplt, clsprty, gndr, age, eduyrs in the logistic regression.
  6. Compare the two models using stargazer.
  7. Plot the predicted probability of voting by years of education.

  # mutating the dependent variable to get rid of any unnecessary rows
