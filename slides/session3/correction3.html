Multinomial Regression

Multinomial Regression

What is a multinomial regression?

When should you use a multinomial regression?

Multinomial Regression

Similar to logistic regression

The dependent variable = categorical variable (K>2)

Run simultaneously different simple logistic regressions

Always the same baseline for the different regressions

Multinommial Regression formula

  • Dependent variable Y (Y=a,…,K)

  • Independent variable X

\[\begin{align} ln \left( \frac{Pr(Y=A|x)}{Pr(Y=K|x)} \right) &=\beta_{0,A} + \beta_{1,A}X \\ ln \left( \frac{Pr(Y=B|x)}{Pr(Y=K|x)} \right) &=\beta_{0,B} + \beta_{1,B}X \\ &\vdots\\ ln \left( \frac{Pr(Y=K-1|x)}{Pr(Y=K|x)} \right) &=\beta_{0,K-1} + \beta_{1,K-1}X \\ \end{align}\]

In R

In R, you will need to use the multinom function from the nnet package. In terms of argument, you need to specify three elements.

multinom(formula, data, Hess):

  • formula: specify your equation as Y ~ X

  • data: specify the name of the dataset

  • Hess=TRUE: specify you want the Hessian matrix

Predictive probabilities

To compute the predicted probabilities, you can use the ggpredict() function (as seen in session 2) or you can use the marginaleffects package (and more specifically the plot_predictions() function). This will directly compute the prediction (you do not need to compute them manually).

plot_predictions(model, type="probs", condition=variable, draw=FALSE):

  • model: name of your multinomial model

  • type=“probs”: specify that you want to estimate probabilities (so a value between 0 and 1)

  • condition=variable: specify the independent variable for which you want to compute the predicted probabilities

  • draw=FALSE: to get a data frame with the prediction if draw=TRUE, you will also get a ggplot2 graph.

AIC (Akaike Information Criterion)

The AIC criterion is a criterion that should be used when you compare different models. With only one model, you cannot interpret your AIC. The reason behind this is that there are no thresholds for the AIC model to say that is a bad or acceptable model. The AIC is used when you compare nested models. You should select the model with the smallest AIC because a smaller AIC means that the model fits the data better than the model with a higher AIC.

modelA<-multinom(party~agea+eduyrs+gndr,
                data=model_data,
                Hess=TRUE)

BIC (Bayesian Information Criterion)

Another goodness of fit indicator is the Bayesian Information Criterion. It works similarly to the AIC meaning that you used it to select between models and that you prefer the model with the lowest BIC. The difference between the AIC, is that the BIC will also penalise a model that includes variables that are less useful in your model (to limit problems of overfitting).
